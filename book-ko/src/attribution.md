# 출처와 자료 성격

- 원저자: Alejandro Balderas 및 원 저장소 기여자
- 원 저장소: <https://github.com/alejandrobalderas/claude-code-from-source>
- 원본 공개 사이트: <https://claude-code-from-source.com>
- 한국어판 기준 commit:
  `a6d5e452a8e0dd925c22c407c84611b1994562eb`

원저작물은 Claude Code source map을 분석해 작성한 독립 교육 자료다. 원본
저장소의 설명에 따르면 Claude Code 소스 코드를 포함하지 않으며, 예제 코드는
아키텍처 패턴을 설명하기 위해 새로 작성한 의사코드다.

이 한국어판은 원본의 장 구조, 논지와 설계 교훈을 한국어 독자가 따라갈 수 있게
정리한 무료 참고판이다. 원문을 대체하지 않으며, 세부 구현과 전체 서사는 각 장의
원문 링크에서 확인한다.

이 자료와 한국어판은 Anthropic, PBC의 공식 문서가 아니며 Anthropic의 승인이나
보증을 받지 않았다. Claude Code는 Anthropic의 제품이다.
