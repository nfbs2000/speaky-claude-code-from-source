# 한국어판을 읽는 법

이 책은 [Claude Code from Source][upstream]의 7부 18장 구조를 그대로 따라가는
한국어 동반판이다. 원저자는 source map에서 확인한 대규모 TypeScript 구조를
분석한 뒤, 원본 소스 한 줄도 싣지 않고 독립적인 의사코드와 기술 서사로
재구성했다.

이 책의 시각은 기능 사전이 아니다. 다음 실행 경로를 처음부터 끝까지 따라간다.

```text
프로세스 부팅
  -> 상태와 API
  -> 에이전트 루프
  -> 도구와 권한
  -> 동시 실행
  -> 서브에이전트와 조정
  -> 메모리와 확장
  -> UI와 입력
  -> MCP와 원격 실행
  -> 성능과 설계 원칙
```

각 장은 원문의 핵심 논지와 `Apply This`를 한국어로 옮기고, 원문 장으로 직접
이동하는 링크를 제공한다. 세부 수치와 구현 설명은 고정 commit
`a6d5e452a8e0dd925c22c407c84611b1994562eb`의 원문을 기준으로 한다.

Claude Agent SDK 강좌는 공개 이벤트에서 무엇을 관찰할 수 있는지 묻는다.
이 책은 그보다 안쪽의 구현을 하나의 실행 경로와 재사용 가능한 설계 패턴으로
읽는다. 두 자료는 경쟁하지 않는다. 서로 다른 층을 설명한다.
